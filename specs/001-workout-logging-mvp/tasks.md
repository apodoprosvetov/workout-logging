  - **Every data-access path filters by `req.userId`.** `WorkoutsService.list` — `WHERE w.userId = :userId` (status/before are `andWhere` on top); `getById`/`deleteById` — `{ id, workoutId } AND { userId }`, `NotFoundException` (404, not 403) on miss, so another user's id and a nonexistent id are indistinguishable (no existence oracle); `deleteById` loads the child graph *through* the user-scoped workout, so the cascade can't touch another user's rows. `IngestionService.ingest` stamps `userId: input.userId` (from the token) on both the Mongo `raw_uploads` doc and the Postgres `workouts` row and the `workout.uploaded` event. `AnalyticsService.weeklyVolume` — Redis key is `weekly_volume:{userId}:{week}`, the Postgres fallback `computeWeeklyVolume` is `WHERE w.user_id = $1`; `?week=` is a date filter only. `AuthService.deleteAccount` — every statement is `WHERE user_id = $1` / `WHERE id = $1` / `{ user_id: userId }` / user-scoped Redis keys. `refresh` rotates a token by its row id + argon2-verified secret and returns *that row's* `userId` — you can't rotate a token whose secret you don't hold, and a deleted user's tokens are already gone (T050 cascade) so it 401s.
  - **Fail-closed if the guard were ever bypassed:** `req.userId` would be `undefined` → Postgres binds `$1 = NULL` → `user_id = NULL` matches nothing (empty result, not everything).
  - **404-not-403 is consistent:** no route returns 403 for an ownership check; guards return 401, ownership misses return a bare `NotFoundException` (`{statusCode:404,message:"Not Found"}` — identical for "other user's" vs "doesn't exist"); `list`/`weekly-volume` return an empty 200 rather than enumerating.
  - **Hardening tests added** (contract suite now 69/69): `workouts.create` — a forged `user_id` field in the multipart body → 400, and the created `workouts.user_id` equals the token `sub`; `workouts.list` — a tampered-signature bearer token → 401. Pre-existing isolation coverage confirmed still present: `workouts.get`/`workouts.delete` "404 not 403 for another user's workout", `workouts.list` "excludes another user's workout", `analytics.weekly-volume` "another user does not see this user's volume", `auth.account` "does not touch another user's data", and a `401 without Authorization` on every authenticated route.
