## 6. Verification in a real browser

Both lists currently query `status=[needs_review, parsed]` only, so in normal use
every visible row is editable. Reaching a `pending` or `failed` workout means the
detail view or the edit address directly — 5.2 and 6.5 are where the status
condition is actually observable.
